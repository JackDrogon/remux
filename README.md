# remux

A small Rust starter generated by `project`.

## Project Layout

```text
.cargo/config.toml         Cargo aliases
.github/workflows/ci.yml   CI for fmt, clippy, and test
.github/dependabot.yml     Dependency update automation
src/lib.rs                 Reusable library code with unit tests
src/main.rs                Binary entrypoint
```

## Development

```bash
just build
just run
just test
just fmt
just fmt-repo
just lint
just spellcheck
just check
just pre-commit
just docs
```

## Environment

Copy `.env.example` to `.env` if you want a local place to track runtime variables.

## Notes

- Generated for c in 2026.
- Uses Cargo for builds, tests, and linting.
- Includes rustfmt, clippy, dprint, typos, editor, dependabot, and CI configuration inspired by larger Rust projects.
- Install [`typos`](https://github.com/crate-ci/typos) locally if you want `just spellcheck`, `just check`, or `just pre-commit` to pass.
- Build artifacts are written to `target/`.
